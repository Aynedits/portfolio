AYAAN VIDEO EDITOR PORTFOLIO
============================

FILES
- index.html: website structure and content
- style.css: responsive dark burgundy styling
- script.js: mobile menu, scroll reveal animations, current year
- assets/: place your images/videos here

HOW TO USE
1. Extract the ZIP.
2. Open index.html in a browser to preview.
3. Upload index.html, style.css, script.js and the assets folder to your GitHub
   repository (keep the same folder structure).
4. Commit/push the files. GitHub Pages will publish the update.

IMPORTANT CUSTOMISATIONS
- In index.html, replace the two sample Google Drive folder URLs containing
  1YOUR_RANKING_FOLDER_ID and 1YOUR_TRAVEL_FOLDER_ID with your actual public
  folder links.
- Replace the sample graphic thumbnails with your own work thumbnails or
  video embeds when ready.
- Update the testimonials section with real client feedback only after getting
  permission to publish it.
- Contact email and YouTube link are already filled in.

DESIGN NOTES
Dark/black base, burgundy and maroon accents, cream typography, responsive
layout, subtle blurred ambient shapes, scroll reveal animations, ranking edits,
travel cinematic edits, tools and testimonials sections. No CapCut listing.
